# ফটো ভিডিও রিকভারি (Photo Video Recovery)

**রুট ছাড়া** ফোন থেকে ডিলিট হয়ে যাওয়া ছবি, ভিডিও আর ফাইল (PDF, DOCX, XLSX ইত্যাদি) খুঁজে বের করে আবার গ্যালারিতে ফিরিয়ে আনার অ্যান্ড্রয়েড অ্যাপ। পুরো প্রজেক্ট GitHub-এ রেখে **GitHub Actions** দিয়ে APK বিল্ড হয় — নিজের কম্পিউটারে Android Studio লাগে না।

---

## ⚠️ প্রথমেই সত্যি কথাটা পড়ুন (রুট ছাড়া যতটুকু সম্ভব)

রুট ছাড়া Android কোনো অ্যাপকেই ডিস্কের ফ্রি স্পেস সরাসরি পড়তে দেয় না — তাই **যে ফাইল বহু বছর আগে ডিলিট হয়ে গেছে এবং যার জায়গায় নতুন ডেটা লেখা হয়ে গেছে, সেটা রুট ছাড়া কোনো অ্যাপেই সবসময় ফেরানো সম্ভব না**। এটা শুধু এই অ্যাপের না, প্লে স্টোরের যেকোনো "রিকভারি" অ্যাপের সীমাবদ্ধতা (ওদের "৫ বছরের পুরনো ফাইলও রিকভার!" বিজ্ঞাপন মূলত ভুয়া ফাইল দেখায়)।

এই অ্যাপ **যেসব রিয়েল পথ** ব্যবহার করে — যেগুলোতে সত্যিই ফাইল ফেরা যায়:

1. **ট্র্যাশ রিস্টোর (Android 11+)** — সিস্টেম ট্র্যাশ/রিসাইকেল বিনে থাকা ছবি-ভিডিও (Google Photos-এর ট্র্যাশসহ) MediaStore ট্র্যাশ API দিয়ে সরাসরি গ্যালারিতে রিস্টোর করে। গুগল ফটোস ট্র্যাশে সাধারণত ৬০ দিন পর্যন্ত ফাইল থাকে।
2. **`.trashed-` ফাইল রিকভারি** — ফাইল ম্যানেজার/গ্যালারি দিয়ে ডিলিট করা ফাইল অনেক সময় `.trashed-<সময়>-<নাম>` নামে ডিস্কেই পড়ে থাকে; অ্যাপ সেগুলো খুঁজে বের করে আসল নামে কপি করে ফেরত দেয়।
3. **গভীর স্ক্যান (Deep Scan)** — ফোনের পুরো স্টোরেজ ঝালিয়ে এমন সব ছবি/ভিডিও/ডকুমেন্ট খোঁজে যেগুলো **গ্যালারির ইনডেক্সে নেই** কিন্তু ডিস্কে এখনো আছে: লুকানো ফোল্ডার, `.nomedia` ফোল্ডার, পুরনো `.thumbnails` ক্যাশ (বহু বছরের পুরনো ছবির থাম্বনেইল এখানে থাকতে পারে), SD কার্ডের অব্যবহৃত ফাইল ইত্যাদি। বর্তমান গ্যালারিতে যে ফাইল আছে সেগুলো স্বয়ংক্রিয়ভাবে বাদ দেওয়া হয় — ফলে শুধু "হারানো" ফাইলগুলোই দেখা যায়।

**কত পুরনো ফাইল পাওয়া যাবে?** সত্য উত্তর: যতদিনের ফাইল এখনো ডিস্কে বাকি আছে ততদিনের। কারো ক্ষেত্রে ৩–৫ বছরের পুরনো থাম্বনেইল/লুকানো ফাইলও মিলে যায়, কারো ক্ষেত্রে ১ মাসেরও কম। যত আগে অ্যাপটি ইনস্টল করে স্ক্যান করবেন, তত বেশি পাওয়ার সম্ভাবনা। অ্যাপে **১ বছর+ / ৩ বছর+ / ৫ বছর+** ফিল্টার চিপ দেওয়া আছে — পুরনো ফাইলগুলো আলাদা করে দেখতে পারবেন।

> 💡 গুরুত্বপূর্ণ ফোন হারানোর পর যতটা সম্ভব কম ফটো/ভিডিও নিন ও ইনস্টল করুন — নতুন ডেটা লেখা হলে পুরনো ফাইল ওভাররাইট হয়ে যায়।

## ✨ ফিচার

- **৩টি আলাদা ক্যাটাগরি:** 📷 ছবি · 🎬 ভিডিও · 📄 ফাইল (PDF, DOC, DOCX, XLS, XLSX, PPT, TXT, ZIP, RAR)
- **ছবি ও ভিডিও:** এক সারিতে ৩টি করে (৩-কলাম গ্রিড) প্রিভিউ; ছবি/ভিডিওতে ক্লিক করলে ফুল-স্ক্রিন প্রিভিউ (ভিডিও হলে সরাসরি চলে), নিচে **"রিকভার করুন"** বাটন — চাপলেই গ্যালারিতে ফিরে যায়
- **ফাইল ক্যাটাগরি:** লিস্ট ভিউ, ভিউয়ার দিয়ে খোলা যায়, রিকভার করলে `Documents/RecoveredFiles`-এ সেভ হয়
- **পুরনো ফাইল ফিল্টার:** সব / ১ বছর+ / ৩ বছর+ / ৫ বছর+ চিপ
- **গ্যালারির বর্তমান ফাইল দেখায় না** — শুধু ডিলিট/হারানো ক্যান্ডিডেট
- **রুট একদম লাগে না** — সব কাজ Android-এর অফিসিয়াল API দিয়ে
- ১০০% অফলাইন: কোনো ইন্টারনেট পারমিশন নেই, ফাইল কোথাও পাঠায় না
- বাংলা ইউজার ইন্টারফেস, Android 7.0 (API 24) থেকে Android 14+ পর্যন্ত

রিকভার করা ছবি যায়: `Pictures/RecoveredPhotos` · ভিডিও: `Movies/RecoveredVideos` · ফাইল: `Documents/RecoveredFiles`

## 🚀 GitHub দিয়ে APK বিল্ড (ধাপে ধাপে)

### ধাপ ১: রিপোজিটরি বানান ও ফাইল আপলোড
1. [github.com/new](https://github.com/new) — ফ্রি অ্যাকাউন্ট খুলে নতুন **Public** রিপোজিটরি বানান (যেমন `PhotoVideoRecovery`)।
2. এই ফোল্ডারের **সব ফাইল** (`.github/`, `app/`, `build.gradle`, `settings.gradle`, `gradle.properties`, `.gitignore`, `README.md`) ঠিক একই স্ট্রাকচারে আপলোড করুন। GitHub-এর ওয়েব "Add file → Upload files" দিয়ে ড্র্যাগ-অ্যান্ড-ড্রপ করলেই চলে।

### ধাপ ২: Actions চালু করুন
3. রিপোতে **Actions** ট্যাবে যান। ওয়ার্কফ্লো ফাইল থাকায় পুশ করার সাথে সাথেই **"Build APK"** জব চালু হবে। চালু না হলে "Build APK" সিলেক্ট করে **Run workflow → Run** চাপুন।
4. প্রথমবার ৫–১০ মিনিট লাগে (সব ডিপেন্ডেন্সি ডাউনলোড হয়)। সবুজ ✅ টিক দেখলে বিল্ড সফল।

### ধাপ ৩: APK ডাউনলোড ও ইনস্টল
5. বিল্ড পেজের নিচে **Artifacts** সেকশনে **`PhotoVideoRecovery-APK`** ডাউনলোড করুন (ZIP-এর ভেতরে দুটি APK)।
6. ZIP খুলে **`PhotoVideoRecovery-v1.0.apk`** (রিলিজ) বা **`PhotoVideoRecovery-debug.apk`** — যেকোনো একটি — ফোনে কপি করে ট্যাপ করুন। "Unknown sources/অজানা উৎস" অনুমতি চাইলে দিয়ে দিন।
7. **Release বানাতে চাইলে:** রিপোর **Releases → Draft a new release → Choose a tag**-এ `v1.0` টাইপ করে পাবলিশ করুন — Actions অটোমেটিক APK সহ রিলিজ বানিয়ে দেবে, লিংক দিয়ে যে কাউকে শেয়ার করতে পারবেন।

## ❓ FAQ

**প্র: স্ক্যানে কিছুই/কম দেখালো কেন?**
উ: (১) "সব ফাইল অ্যাক্সেস" দেওয়া আছে কি না দেখুন; (২) Android 11-এর নিচে মিডিয়া অনুমতি ছাড়া গভীর স্ক্যান চলে না; (৩) বহু বছর আগের ফাইল ডিস্ক থেকে মুছে গেলে রুট ছাড়া আর পাওয়া যায় না — উপরের সীমাবদ্ধতা অংশ পড়ুন।

**প্র: রিকভার চাপলে সিস্টেম ডায়ালগ এলো, কী করব?**
উ: Android 11+ ট্র্যাশ থেকে রিস্টোরের সময় সিস্টেম নিজেই কনফার্মেশন চায় — **Allow** দিন, ফাইল গ্যালারিতে ফিরে যাবে।

**প্র: এই অ্যাপ কি ডেটা চুরি করে?**
উ: না। ইন্টারনেট পারমিশনই নেই — সব স্ক্যান ও রিকভারি ফোনের ভেতরেই হয়। কোড ওপেন সোর্স, নিজে যাচাই করতে পারেন।

**প্র: নিজের ফোনে ডিরেক্ট বিল্ড করতে চাই?**
উ: Android Studio (Ladybug+) দিয়ে ফোল্ডার খুলে ▶ চাপলেই হবে; JDK 17 লাগবে।

## 🧱 টেকনিক্যাল ডিটেইলস

- **ভাষা:** Kotlin · **UI:** Material 3 (BottomNavigation + ৩ Fragment) · **ছবি লোড:** Glide
- **স্ক্যান:** MediaStore (IS_TRASHED=1 কোয়েরি, API 30+) + রিকার্সিভ ডিস্ক ওয়াক (৯০ সেকেন্ড/৫০০০ ফাইল বাজেট) + MediaStore ইনডেক্স-ডিফ ফিল্টার
- **রিকভারি:** `MediaStore.createTrashRequest(uri, false)` (সিস্টেম কনফার্মেশন) অথবা MediaStore insert (`Pictures/Recovered*`, `IS_PENDING` ফ্লো) + `MediaScannerConnection.scanFile`
- **বিল্ড:** AGP 8.2.2, Kotlin 1.9.22, Gradle 8.7 (GitHub Actions `gradle/actions/setup-gradle@v4`), JDK 17
